# 专业知识细粒度路由与联网检索

## 目录

- 先判断是否需要联网
- 主题路由
- 来源优先级
- 搜索与证据提取
- 回答方式

## 一、先判断是否需要联网

### 通常不需要联网

- 以陪伴、意义探索或自我理解为主，专业概念只是辅助。
- 本地核心书目与扩展书库已经足够解释稳定的理论框架。
- 用户没有要求精确出处、最新研究或治疗建议。

### 必须联网查证

- 用户明确要求“查一下、找研究、给出处、最新证据”。
- 涉及诊断标准、治疗有效性、药物、医疗或法律建议、危机资源、流行率和统计数字。
- 需要精确引文、页码、版本、发布日期或作者原意。
- 本地书目之间存在冲突，或知识可能因指南更新而变化。
- 回答将影响用户是否寻求、停止或改变专业治疗。

联网不能把本 skill 变成诊断或治疗服务。对医疗与治疗决策只提供一般信息，并鼓励与合格专业人员讨论。

## 二、主题路由

每次确定一个主主题，必要时添加一个次主题：

| 用户问题 | 本地首选 | 扩展首选 | 联网检索重点 |
|---|---|---|---|
| 被理解、自我接纳、咨询式倾听 | Rogers | CFT、人本主义资料 | APA 人本／来访者中心资料 |
| 意义、孤独、自由、死亡 | Yalom | ACT、Frankl | 存在心理学综述；避免把哲学当疗效结论 |
| 情绪混乱、压抑、爱恨并存 | Greenberg | Gross 情绪调节、DBT | 情绪调节综述、适用人群与局限 |
| 犹豫、改变、做决定 | Miller & Rollnick | ACT | 动机式访谈或决策支持的系统综述 |
| 反刍、灾难化、自我否定 | Beck | ACT、模式疗法 | CBT／反刍相关指南与综述 |
| 亲密焦虑、追逐—退缩 | Susan Johnson | Cassidy & Shaver | 成人依恋研究；不得用量表远程定型 |
| 冲突、修复、长期关系 | Gottman | 家庭系统、伴侣治疗手册 | 伴侣研究、文化与样本限制 |
| 自责、羞耻、自我攻击 | Neff | Gilbert CFT | 自我关怀／慈悲干预综述 |
| 失恋、死亡、告别与哀伤 | Worden | CFT、持续性哀伤资料 | WHO、APA、NICE 与哀伤研究；区分正常哀伤和诊断 |
| 价值、接纳、活在当下 | ACT | DBT、正念资料 | 心理灵活性研究和系统综述 |
| 家庭角色、代际互动 | 家庭系统 | 依恋手册 | 家庭结构与文化背景资料 |
| 反复关系脚本、长期模式 | 模式疗法 | CBT、依恋 | 不把“图式”当人格诊断 |
| 情绪调节与沟通技能 | Gross、DBT | 非暴力沟通 | 技能适用性；避免冒充完整治疗方案 |
| 暴力、创伤和控制关系 | Herman | 权威创伤指南 | WHO／NICE／专业创伤组织；安全优先 |

## 三、来源优先级

按问题选择，不要机械搜满所有层级：

1. **临床或公共卫生指南：** WHO、NICE、APA 及所在地卫生主管部门。
2. **高质量证据综述：** Cochrane、同行评议的系统综述或荟萃分析。
3. **原始研究：** 当综述缺失或用户询问某项具体研究时使用，说明样本和设计限制。
4. **专业教材与正式出版社：** 核对稳定理论、版本和作者原意。
5. **专业组织的公众资料：** 用于通俗解释，不替代证据综述。

不要以搜索引擎摘要、百科、商业诊所营销页、社交媒体、无作者博客或 Agent Marketplace 页面作为关键专业结论的依据。

## 四、搜索与证据提取

1. 将问题写成“主题 + 人群／情境 + evidence review／guideline／systematic review”。
2. 优先限定权威域名；技术与专业问题只依赖原始研究、正式指南或出版社资料。
3. 对每个关键结论记录：来源、发布日期、证据类型、适用人群、局限和是否直接支持该结论。
4. 一般回答使用一到三项高相关来源即可。来源之间不一致时说明分歧，不投票决定真相。
5. 新闻稿只能用于发现原始指南或论文，不能代替原始来源。
6. 只引用实际打开并核对过的页面；不要根据搜索标题推断内容。

## 五、回答方式

- 先回应用户的经验，再自然引入专业解释。
- 将“书中的稳定框架”和“联网查到的当前证据”分开，不让经典理论冒充最新研究。
- 对专业主张使用近邻链接引用；用户没要求研究报告时只保留最必要的来源。
- 明确区分“研究平均结果”和“对这个用户的可能解释”。研究不能替用户做个体诊断。
- 当证据不足、样本局限或文化适配未知时直接说明。
- 不复制长段原文，不虚构页码；精确引文应短而可核验。
